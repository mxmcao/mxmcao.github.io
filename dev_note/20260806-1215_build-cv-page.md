# 完成 terminal 风格 CV 页面

## 改动背景和目标

旧 CV 页面只有归档提示。本次根据 `prev-information/personal/CV-2026.pdf` 的教育、出版、实习、奖项和技能信息，补齐公开 CV；删除 Summary，并将实习内容压缩为单行职责摘要。同时接入当前 publication 数据，保证最新论文与 Research 页面保持同步。

## 修改文件及具体内容

- `content/cv.md`：使用新的 `cv` layout，移除旧 CV 占位文案。
- `data/cv.yaml`：新增联系方式、教育经历、实习经历、奖项与技能数据，并补充 IQuest、NBG Lab 两段最新经历。
- `layouts/_default/cv.html`：新增数据驱动的 CV 页面结构，包含 education、publications、experience、awards & honors 和 skills 分区。
- `static/style.css`：增加终端式 CV 专属样式，包括 `$` 联系信息行、`>_` 分区标题、时间列、虚线节奏和移动端响应式布局。

## 核心实现说明

CV 的 publication 列表直接遍历 `site.Data.publications`，作者、年份、venue 和 arXiv 链接不会在 CV 模板中重复维护。经历内容使用短句 focus 字段，避免 PDF 中较长的项目 bullet 破坏页面阅读节奏。

## 关键代码摘录

```go-html-template
{{ range site.Data.publications }}
  {{ range .papers }}
    <li class="cv-publication">…{{ .title }}…{{ .venue.short }}…</li>
  {{ end }}
{{ end }}
```

对应文件：`layouts/_default/cv.html`。

## 实际执行的测试和结果

- `hugo --minify --destination <temporary-directory>`：通过。
- `git diff --check`：通过。
- 检查生成的 `/cv/index.html`：包含 education、4 篇当前 publication、4 段 experience、awards & honors 和 skills；不包含 Summary。

## 已知风险或未验证内容

- IQuest（2026-07 至今）和 NBG Lab（2026-03 至 2026-06）的时间范围依据仓库 `data/news.yaml` 的入职新闻和时间顺序整理；如有正式 CV 中的准确月份，应再替换。
- 未在浏览器中逐项检查打印分页效果；当前 CSS 仅针对屏幕展示和响应式阅读进行验证。
