## BibTeX 扩展字段

- `abbr`：venue 简称，用于 banner 和 venue 链接。
- `preview`：论文缩略图文件名。
- `arxiv`：arXiv ID，旧站显示为 PDF 按钮。
- `website`：项目或代码地址，旧站显示为 Code 按钮。
- `bibtex_show`：是否显示 BibTeX 展开按钮。
- `github`：`owner/repo`，用于 GitHub stars/forks 徽章。
- `google_scholar_id`：个人 Scholar profile 中的论文 ID。
- `huggingface`、`huggingface_name`：Hugging Face 链接和徽章名称。
- `altmetric`：是否启用 Altmetric 徽章。
- `selected`：是否在首页 selected publications 中展示。

当前 `citations.yml` 的最后更新时间是 2026-07-22。它是快照，不应视为实时数据。
